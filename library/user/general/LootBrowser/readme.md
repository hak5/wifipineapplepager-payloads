## Description

The RootJunky Loot Browser is a lightweight, mobile-friendly web interface for the Hak5 WiFi Pineapple Pager that allows you to conveniently browse and manage access to your collected loot files from a phone, tablet, or computer. It automatically detects the Pager’s Client and Management network interfaces and lets you choose which network to use, then launches a dedicated web server on port 8088 without interfering with the Pager’s built-in web server. The browser provides read-only access to folders and files within the loot directory, including archived Wi-Fi handshake captures, packet captures, logs, text files, and other reconnaissance data. Users can navigate folders, search filenames, preview supported text files, and download files directly to their device. A QR code provides quick access to the browser, while path validation and directory-boundary checks help prevent access to files outside the designated loot directory. Designed with a dark purple RootJunky theme and a responsive mobile-first layout, the Loot Browser makes accessing and reviewing collected data on the WiFi Pineapple Pager simple and convenient.
